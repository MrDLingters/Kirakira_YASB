# Kirakira_YASB
### Minimalistic bar with glass design with dynamic theme support.
Requires YASB v2.0.7 or newer.

Fonts required:
- JetBrainsMono Nerd Font Propo
- Segoe Fluent Icons

Change image_path in the wallpapers widget to your own wallpaper folder.
